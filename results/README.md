# Results

Output tables from the original run (release v1.0), as written by
`notebooks/02_benchmark.ipynb` to `outputs/tables/`. They let any number in
the manuscript be checked without re-running the benchmark; the main README lists
which table holds which result.

Also included:

- `master_summary_all_K_k3.csv`: full Step 16 summary (k = 3 neighbourhood).
- `bregma_class_coverage_874k.csv`: cells per class and section (Step 14), used for Figure 2.
- `config_v20.json`: run settings saved by Step 15. The current notebook names
  this file `config.json`; the paths inside point to the Google Drive used for the run.
